# Examples

Plain `.py` scripts with `# %%` cell markers rather than `.ipynb`. They run as
scripts, review as diffs, and open as notebooks in VS Code / Jupytext if you
want cells. Notebook JSON in git is a merge conflict waiting to happen.

| | |
|---|---|
| `01_offline_tau_ext.py` | annotate a recorded episode, no hardware needed |
| `02_estimate_payload.py` | estimate the mass of a held object |
