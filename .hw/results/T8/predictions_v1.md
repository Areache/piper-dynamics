# T8 冻结的预测与判据（v1，2026-11-11，上机前写定）

本文件的 md5 记在任务板 T8 条目里。数据回来后由 `hw_scripts/t8/t8_analyze.py` 按下面的定义逐条判定，**事后不改**；要改就另写 v2，两版结果都报。

## 0. 共同定义

- **残差力矩。** τ_res,j = dir_j · kt_j · i_j − g_j(q)。其中 i 是 A，g 是带夹爪 URDF 的重力力矩，dir 取 T4 的符号；没有特别说明时 kt 取标称 k·b·c。
- **载荷签名。** γ(q) = J_p(q)ᵀ·(0, 0, 9.81)，单位 N·m/kg，只看 j2–j5。J_p 是容器质心点的位置雅可比。
  - 质心点 = 指尖沿工具轴偏移 d_com。d_com 由操作员量出并写进结果；量不出就取 0，同时报告 ±1 cm 的敏感度。
- **质量估计。** m̂ = γᵀ W Δτ / (γᵀ W γ)，权重 W = diag(1/σ_j²)。σ_j 用第 0 档静态读的同位姿重访散布估计。Δτ 是同位姿、同接近方向下，与第 0 档（空容器）的差。
- **容器内装质量。** 一律用秤上读数，不用标称值。

## P1 增益（步骤 3a 静态读）

- **拟合。** 每个关节 j2–j5 做一次回归：y = dir·k·b·c·Δi，x = Δm·γ_j。数据是 10 姿态 × 2 接近方向 × 3 个非零档，共 60 点。
  - 斜率 b_j 是标称力矩与真实力矩之比，增益比 r_j = 1/b_j = kt_真 / k·b·c。
  - 95% 区间按姿态整组 bootstrap，2000 次。
- **P1a 成立的条件**：j2–j5 每个 r_j 的 95% 区间上界都 < 1.0，即增益低于标称，方向与 T4 的 kt 比值（0.57–0.91）一致。
- **P1b 成立的条件**：j4、j5 的 1/r_j 点估计都 ≥ 1.05，且 95% 区间都与 [1.1, 1.3] 有重叠。也就是说，这 1.1–1.3 倍的尺度可以由增益解释。
- **判定**：P1a 和 P1b 都成立才算 P1 成立；只成立一条就报「部分」。

## P2 关节周期波动（步骤 2 扫描）

- **波动表。** 每个关节、每段扫描都按 `plan_ripple_v1` 的做法处理：
  1. τ_res 换到角度域，按 0.005° 网格重采样；
  2. 角度域带通，周期 0.1–3°；
  3. 两个构型 × 两个方向 × 两遍取平均，得到 W_j(θ)。
  4. 另报两个比值：构型 A 与 B 的幅值比（看与负载的关系），上行与下行的幅值比。
- **P2a 相位一致。** 在 E3 的窗口里（j2 89.3–96.3°，j3 −72.0 到 −56.6°），把 W_j 和 E3 A0+A1 的参考波形比较。
  - 零滞后相关 ≥ 0.5，且最佳平移的绝对值 ≤ 0.1 个周期（j3 周期 1.00°，j2 周期 0.156°），判为一致。
  - 10-22 那一组与 T8 重叠的部分照同一规则，只报告，不进判定。
- **P2b 扣除后中频下降。** 留出数据是 E3 A0/A1 的全部自由下降段。
  - 在 0.5–5 Hz 频带里，比较扣除 W_j(θ(t)) 前后的方差。
  - j3 的方差下降中位数 ≥ 25%，j2 ≥ 15%，并且两者的 Wilcoxon 符号秩检验 p < 0.05，才判为成立。
  - 阈值的依据：E3 里 j3 的 1.00° 波动连同谐波约占这个频带功率的 49%，j2 的几个峰合计约 30–40%；要求表能吃掉其中一半左右。
  - T8 步骤 3c 空容器（第 0 档）往复段上的下降量只报告，不进判定。这一段有起停和停顿，频带里混进了别的东西。
- **判定**：P2a 和 P2b 都成立，P2 才成立。

## P3 静态读（步骤 4 长保持 + 步骤 3a）

- **P3a 保持时长。** 用步骤 4 的数据：3 个姿态 × {空容器, 500 g}，每格 3 次重访，每次保持 10 s。
  - 每次重访取两个窗口算 m̂：停稳后的前 2 s，以及完整的 10 s。
  - d′ = (500 g 组均值 − 空容器组均值) / 格内重访标准差，标准差在 3 个姿态间合并。
  - 判定看比值 d′₁₀ / d′₂：< 1.3 判为成立（保持更久没有帮助）；> 1.8 判为不成立（像白噪声，白噪声预期是 √5 ≈ 2.24）；介于两者之间判为「不确定」。
- **P3b 接近方向。** 用步骤 3a 的数据。
  - 对每个姿态、每一档，算 D_j = τ_res,j(从上方接近) − τ_res,j(从下方接近)，只看 j2 和 j3。
  - 先在各档之间平均，每个姿态得到一个值（10 个），再做单样本 t 检验。
  - j2 或 j3 任一个 p < 0.01，判为成立（两个方向的常值不同）。
- **判定**：P3a 和 P3b 分别报告。

## P4 离桌事件（步骤 3b）

- **信号。** m̂(t) 用抓取位姿的 γ，增益取 P1 的结果。
- **匀速穿过的台阶。** 取两段 m̂(t) 的均值相减，再减去第 0 档同一抬法的均值：
  - 抬升的匀速段：抬起指令后 1.0 s 到抬升结束前 0.5 s；
  - 抬起指令前，夹爪宽度稳定的 0.3 s。
- **停后再抬的静态差。** 抬起后静止 2 s 的均值，减去抬起前静止 2 s 的均值，再减去第 0 档同一抬法的均值。
- **散布。** 每档内，取估计值与秤上读数之差，算标准差，四档合并（每种抬法各 16 个自由度）。比较 SD_穿过 / SD_停：
  - 结果 A，「偏置重抽由停下引起」：比值 < 0.6，且单侧 F 检验 p < 0.05；
  - 结果 B，「载荷变化本身会重抽」：比值在 [0.7, 1.43] 内；
  - 其他情况：「不确定」。
- 两种结果都照实报告，P4 不分成立或不成立。
- **检验力不足（干跑）。** 仿真里真值是 A（偏置只在停下时重抽），这一判据却给出比值 0.75，判为 B。原因是匀速段本身有约 30 g 的噪声底，和停下重抽的散布同一量级。所以真机给出 B 时，要同时报告第 0 档「匀速穿过」的散布；只有它明显小于「停后再抬」的散布时，B 才算对 A 的反证。

## P5 改变力臂（步骤 3c）

- **斜率。** 每档往复 3 个来回，伸出和收回各 3 段。每段只取匀速部分（1 cm/s ± 2 mm/s），把 τ_res,j2 对指尖的径向位置 x（m）做线性回归，得到斜率 k。
  - 同一来回的伸出和收回取平均，每档得到 3 个估计。这样可以抵掉与方向有关的部分（干跑里两者系统性不同）。
  - 质量估计 m̂ = (k − 第 0 档的平均 k) / k₁。k₁ 是模型给出的每 kg 载荷的斜率：在同一批样本上把 γ_j2 对 x 回归得到。
  - 回归分两种做：先扣掉 W_j(θ)，以及不扣。
- **P5a 线性。** 用扣掉 W 的版本，12 个来回的 k 对秤上质量做回归，R² ≥ 0.9。
- **P5b 分辨率。** σ_m(力臂读，扣 W) ≤ σ_m(静态读)。两者都是各档内 m̂ 与秤上读数之差的标准差，四档合并。
- **P5c 波动表的作用。** σ_m(力臂读，不扣 W) ≥ 1.2 × σ_m(力臂读，扣 W)。
- **判定**：P5a、P5b、P5c 三条都成立，P5 才成立。

## P6 柔顺（步骤 4 外部量测）

- **外部下沉量。** 在 2 个姿态上，取两组外部读数各自的均值相减：容器内装 500 g 的那几步，减去空容器的那几步。
- **编码器上报的下沉。** 由编码器读数 q 做正运动学，得到指尖 z，两组同样相减。
- **判定**：两个姿态的外部下沉都在 [1.0, 4.0] mm 内（按 4.9 N / 约 2 N/mm ≈ 2.4 mm 推算），并且编码器上报的变化都 ≤ 0.3 mm，判为成立。
- 外部量测方法（千分表、尺子或相机）写进结果；方法分辨率比 0.3 mm 还粗时，P6 判为「不可判」。

## P7 温度（步骤 1 和步骤 5 的三角波）

- **库仑项。** 每个关节 j1–j5，在三角波的匀速平台段（速度在平台值 ±20% 以内）上：
  - 估计 Fc = (τ_res 在 v > 0 时的均值 − τ_res 在 v < 0 时的均值) / 2；
  - j2–j5 的 kt 取 P1 的结果，j1 取标称。
  - 95% 区间按往复段做 bootstrap。
- **判定**：5 个关节里至少 4 个满足 Fc_热 < Fc_冷，判为成立。
- 冷、热两组的电机温度中位数相差不到 5 °C 时，P7 判为「不可判」。

- 不剔除数据点；只有操作员当场标注的事件（碰撞、掉落、被手碰到）可以剔除，并且要列出来。
